# Threat Model

Grounded threat model for the FinOps & Tokenomics Analytics Platform (`finops_dashboard/`, `app/`, `deploy/`). Every entry point, trust boundary, sensitive data path, and security control below maps directly to code in this repository.

## 1. Entry Points & Surface Isolation

The runtime is served by [app/fast_api_app.py](../app/fast_api_app.py) and [finops_dashboard/server.py](../finops_dashboard/server.py). Setting `FINOPS_SURFACE` (`mcp` vs. `dashboard`, provisioned via `FINOPS_SPLIT_EDGE=1` in [deploy/deploy_cloud_run.sh](../deploy/deploy_cloud_run.sh)) partitions the HTTP routes across two private Cloud Run services:

| Surface | Service | Exposed Routes | Authentication Boundary |
| :--- | :--- | :--- | :--- |
| `mcp` | `finops-dashboard-mcp-app` | `GET /healthz`, `GET /api/health`, `GET /.well-known/agent-card.json`, `GET /a2a/app/.well-known/agent-card.json`, `POST /a2a/app`, `GET/POST/DELETE /mcp` | `--no-allow-unauthenticated`; Cloud Run IAM `roles/run.invoker` granted to `service-PROJECT_NUMBER@gcp-sa-discoveryengine.iam.gserviceaccount.com` and `SCHEDULER_SA_EMAIL` |
| `dashboard` | `finops-tokenomics-dashboard` | `GET /`, `GET /ui`, `GET /app`, `GET /api/state`, `GET /api/ge_fleet`, `GET /api/gcp_telemetry`, `GET /api/antigravity`, `GET /api/antigravity_finops`, `GET /api/user_centric_finops`, `GET /api/tokenomics_cockpit`, `GET /api/validate_telemetry`, `GET /api/prompt_xray/live_turns`, `GET /api/dead_letters`, `GET /api/dead-letters`, `GET /api/governance/clearance_queue`, `GET /api/governance/executive_digest`, `GET/POST /api/governance/snooze`, `POST /api/governance/evaluate_idle`, `POST /api/cron/warn_idle_runtimes`, `POST /api/governance/execute_clearance`, `POST /api/cron/execute_scheduled_clearance`, `POST /api/governance/executive_digest`, `POST /api/cron/send_executive_digest`, `POST /api/decorator_ingest`, `POST /api/aive_log`, `POST /api/csat_rating`, `POST /api/validate_telemetry`, `POST /api/select_agent`, `POST /api/select_optimizer`, `POST /api/nl2sql`, `POST /api/what_if_simulate`, `POST /api/what_if_live`, `POST /api/prompt_xray`, `POST /api/recompute_finops`, `POST /api/add_parameter`, `POST /api/reset`, `POST /api/sync_gcp_telemetry`, `POST /api/sync_ge_fleet`, `POST /api/ge_mart/refresh`, `POST /api/enable_agent_observability`, `POST /api/agent_observability` | Cloud Run native IAP (`--iap`) + Cloud Armor WAF (`finops-waf-policy` in [deploy/setup_enterprise_perimeter.sh](../deploy/setup_enterprise_perimeter.sh)) |

## 2. Trust Boundaries

1. **Caller -> Cloud Run Edge:** Unauthenticated callers are rejected at the Google Front End (HTTP 403) before container code runs.
2. **Gemini Enterprise Host Bridge -> Sandboxed MCP App Iframe:** `open_dashboard` in [finops_dashboard/mcp_server.py](../finops_dashboard/mcp_server.py) serves self-contained HTML with `DASHBOARD_SECURITY_HEADERS` (`Content-Security-Policy`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`).
3. **Runtime Service Account -> Google Cloud APIs:** Outbound calls in [finops_dashboard/fleet.py](../finops_dashboard/fleet.py), [finops_dashboard/gcp_telemetry.py](../finops_dashboard/gcp_telemetry.py), and [finops_dashboard/cost_governance.py](../finops_dashboard/cost_governance.py) authenticate exclusively as `finops-dashboard-runtime-sa` via the metadata server token (`_get_access_token`) and enforce `https://*.googleapis.com` host validation.
4. **LLM-Generated SQL -> BigQuery:** `verify_nl2sql_sql` in [finops_dashboard/optimizer.py](../finops_dashboard/optimizer.py) enforces a single read-only `SELECT`/`WITH` query, blocks SQL comments (`--`, `/*`), blocks DDL/DML/scripting/`EXTERNAL_QUERY`/`INFORMATION_SCHEMA`, requires backtick-quoted tables inside `allowed_datasets`, and caps scan size at `NL2SQL_MAX_BYTES_BILLED` (100 MiB).

## 3. Threats & Verified Mitigations

| Threat ID | Vector | Code Location | Mitigation |
| :--- | :--- | :--- | :--- |
| **TM-01** | Forged or leaked Keep-Alive snooze links | [finops_dashboard/cost_governance.py](../finops_dashboard/cost_governance.py), [finops_dashboard/server.py](../finops_dashboard/server.py) | `GET /api/governance/snooze` requires a constant-time verified HMAC-SHA256 token (`verify_snooze_token`, signed with `FINOPS_GOVERNANCE_SECRET` and optional expiry timestamp). Public queue and notification payloads redact `token=REDACTED` via `_redact_snooze_tokens`. Tokenless `POST /api/governance/snooze` is restricted to runtimes already present in `self._queue` and capped at 7 days. |
| **TM-02** | Automated runtime clearance safety | [finops_dashboard/cost_governance.py](../finops_dashboard/cost_governance.py) | Stage 2 clearance defaults to `dry_run`. Live Cloud Run scale-to-zero and Reasoning Engine deletion require both `CLEARANCE_MODE=enforced` and `FINOPS_ALLOW_AUTOMATED_CLEARANCE=1`, never touch `protected_runtime_ids()` (`finops-dashboard-mcp-app`, `finops-tokenomics-dashboard`, `K_SERVICE`, `FINOPS_CLEARANCE_EXCLUDE`), and fall back to `dry_run` if BigQuery queue state or fleet metrics cannot be verified. |
| **TM-03** | NL2SQL injection / cross-dataset exfiltration | [finops_dashboard/optimizer.py](../finops_dashboard/optimizer.py) | `verify_nl2sql_sql` rejects multi-statement `;`, SQL comments, unquoted `FROM`/`JOIN`/comma-join tables, `INFORMATION_SCHEMA`, `EXTERNAL_QUERY`, and any dataset outside `allowed_datasets`. |
| **TM-04** | Arbitrary file read via MCP AST linter | [finops_dashboard/mcp_server.py](../finops_dashboard/mcp_server.py) | `_tool_lint_agent_finops` resolves `file_path` with `os.path.realpath` and rejects any path outside the repository workspace root (`os.path.commonpath`). |
| **TM-05** | PII exposure in telemetry, audit logs & emails | [finops_dashboard/ge_mart.py](../finops_dashboard/ge_mart.py), [finops_dashboard/agy_finops.py](../finops_dashboard/agy_finops.py), [finops_dashboard/cost_governance.py](../finops_dashboard/cost_governance.py) | Antigravity log ingestion strips prompt/response text via a strict field allowlist; `FINOPS_PII_REDACT=1` hashes user emails with SHA-256; `mask_email_for_ui` masks creator emails in public governance payloads; dead-letter logs record only field names, byte counts, and SHA-256 digests. Opt-in conversation logging for AQuA (`FINOPS_AGENT_ANALYTICS_DATASET`) is the one path that stores prompts and responses verbatim: it is off by default, writes to a dedicated dataset the runtime SA can write and nothing else, and is read only by AQuA's service account. |
| **TM-06** | Simulator mutation in live production projects | [finops_dashboard/server.py](../finops_dashboard/server.py) | When `_is_live_gcp()` is true and `FINOPS_ENABLE_SIMULATOR` is not enabled, simulator mutation routes (`/api/reset`, `/api/add_parameter`, `/api/recompute_finops`, demo `/api/what_if_simulate`) return `DISABLED_IN_LIVE_MODE`. |
